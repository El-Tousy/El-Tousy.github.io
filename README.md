# leila.dev — Portfolio von Leila El Tousy

Persönliches Portfolio von **mir**, Anwendungsentwicklerin aus Marokko auf der Suche nach einer **Ausbildung als Fachinformatikerin für Anwendungsentwicklung** in Deutschland (Start 2027).

🔗 **Live-Website:** [el-tousy.github.io](https://el-tousy.github.io/)

## Über dieses Projekt

Diese Website stellt meinen Werdegang, meine abgeschlossenen Projekte und meine technischen Fähigkeiten vor. Sie dient als digitale Bewerbungsunterlage für deutsche Unternehmen, die Auszubildende im Bereich Anwendungsentwicklung suchen.

## Inhalt der Seite

- **Über mich** — Kurzvorstellung und aktueller Status der Bewerbung
- **Ausbildung** — Abitur (2023–2024) und DUT Informatik (2024–2026), von der ANABIN als gleichwertig mit einem deutschen Berufsfachschulabschluss anerkannt
- **Projekte** — 6 abgeschlossene Projekte, u. a.:
  - **Alexandra** – KI-Sprachassistent für Android (Kotlin, Java, OpenAI API, Firebase)
  - **Wetter-Überwachungs-Dashboard** – Echtzeit-IoT-Dashboard (PHP, MySQL, Leaflet.js)
  - **Admin-Dashboard Giga Manager** – Verwaltungsdashboard für ein Hosting-Unternehmen (PHP, MySQL)
  - **GLPI 10 → 11 Migration** – containerisierte Migration mit Docker
  - **WhatsApp-Bot** – Meta API + OpenAI
  - **VELO STOR** – Online-Shop (HTML, CSS, JavaScript)
- **Fähigkeiten** — Python, PHP, HTML/CSS, MySQL, REST APIs, Firebase, Git & GitHub u. a.
- **Kontakt** — E-Mail und GitHub-Profil
